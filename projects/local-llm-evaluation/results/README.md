# Results

Place **team evaluation outputs** here:

- Scorecards (CSV / XLSX) by model and dimension  
- Latency and RAM tables  
- AI-as-judge aggregate scores

**Naming:** `results_YYYYMMDD_<eval_set_version>_<model_shortname>.csv`
